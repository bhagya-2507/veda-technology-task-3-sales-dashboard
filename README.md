# VEDA Technology Internship – Day 3 Task 3

## Simple Sales Dashboard Design

This project was created as part of the **VEDA Technology Internship – Level 1, Day 3, Task 3**.

### 📊 Project Overview

An interactive Power BI dashboard was created to analyze sales performance by:

* Product
* Category
* Region
* Month

### 🎯 Objectives

* Track overall sales performance
* Analyze profit and units sold
* Identify monthly sales trends
* Compare category and regional performance
* Identify top-performing products
* Provide interactive filtering for stakeholders

### 📌 KPIs

* Total Sales
* Total Profit
* Units Sold
* Profit Margin

### 📈 Dashboard Visuals

* Monthly Sales Trend
* Sales by Category
* Sales by Region
* Top 10 Products

### 🎛️ Filters

* Region
* Category

### 🛠️ Tools Used

* Microsoft Power BI
* Excel
* DAX

### 📁 Project Files

* `Sales_dashboard.pbix` – Power BI dashboard
* Dashboard screenshot – Preview of the completed dashboard

### 📖 How to Use

Use the Month, Region, and Category slicers to filter the dashboard. The KPI cards and charts update according to the selected filters.
